# История очередей в Google Sheets

`GoogleRepo` реализует `LessonHistoryRepository`. Единственный публичный метод —
`save(lesson, course_name=...)`. Авторизация и таймаут передаются существующей
фабрикой `sheets_client`, без импорта `main` внутри адаптера:

```python
history = GoogleRepo(sheets_client, spreadsheet_id="ID таблицы")
created = await history.save(lesson, course_name=schedule.course_name)
```

Репозиторий вызывается из `QueueHistoryService`; `QueueService` управляет только
загрузкой расписания и объектами очередей в памяти. Обычный вызов приложения:
`await app.state.queue_history_service.save_history(schedule_id, lesson_id)`.

Каждый курс использует отдельный Google-документ. Внутри автоматически создаются
листы недель, например `02.11.2026–08.11.2026`. Неделя определяется по дате
занятия в Москве, а не по моменту выгрузки. ID документа задаётся в YAML курса
как `google.queue-history-spreadsheet`; переменная `QUEUE_HISTORY_SPREADSHEET_ID`
остаётся запасным вариантом для одного курса. Смешивание разных курсов на
недельном листе отклоняется.

Каждое занятие добавляется отдельным блоком:

```text
Занятие: 08.11.2026 · 10:00–11:00
Лабораторное занятие · Группы: 4431
Курс: Операционные системы · Аудитория: 23-09 · Студентов: 2
№ | ФИО          | github | Лабораторная работа | Время записи
1 | Иванов Иван  | ivan   | ЛР 1               | 08.11.2026 09:40
2 | Петров Пётр  | petr   | ЛР 2               | 08.11.2026 09:45
```

Между занятиями две пустые строки. Блоки упорядочиваются по дате/времени, в том
числе при повторе запоздалых сохранений. Оформление простое: белый фон,
Arial, чёрный текст, жирные заголовки и тонкие границы таблицы, без заливок.
Время отображается по Москве. Пустая очередь
получает строку «Очередь пустая». ID не записываются, скрытых технических листов
нет. Метаданные и строки формирует `rows.py`, оформление и запросы —
`formatting.py`, адаптер выполняет запросы в отдельном потоке.

Дата, время, тип и группы в первых двух строках блока определяют повторную
запись в пределах листа курса. `True` — записан новый блок, `False` — блок уже
есть. Изменение аудитории не создаёт дубликат. Ручная правка этих заголовков
может нарушить поиск повторов. Разные занятия с одинаковыми датой, временем,
типом и группами в одном курсе считаются одним занятием.

Значения и оформление записываются атомарно одним spreadsheets.batchUpdate.
Строки передаются как буквальные значения, без выполнения формул из данных.
Существующие блоки не перезаписываются. Если лист уже содержит старый плоский
формат или посторонние данные, запись отклоняется — их следует переносить
отдельно. Ошибки передаются вызывающему коду, чтобы очередь оставалась в памяти.

Для одного листа используйте один общий экземпляр репозитория и один процесс
backend: локальная блокировка не защищает от параллельных внешних писателей.
Тесты `queues/tests/test_google_repo.py` используют моки без настоящих записей.
