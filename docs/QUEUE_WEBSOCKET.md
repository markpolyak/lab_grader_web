# Обновление открытой очереди

При открытии очереди студент или преподаватель подключается к `/ws` и отправляет:

```json
{"action":"subscribe","event_id":"UUID очереди / занятия"}
```

Сервер подтверждает подписку сообщением `subscribed` с `event_id`. Frontend
перечитывает HTTP-снимок после подтверждения, в том числе после переподключения.
Команды изменения очереди выполняются через прежние HTTP-эндпоинты.

После успешного изменения HTTP-обработчик уведомляет только подписчиков очереди:

```json
{"type":"queue.updated","queue_id":"UUID очереди"}
```

Событие отправляется при записи/выходе студента, вызове, завершении, изменении
результата, удалении записи, изменении времени/отмене занятия и открытии/закрытии
записи. Ошибки сохранения и повторное открытие уже открытой очереди
не отправляют уведомления. Удаление через HTTP отправляет `queue.deleted`.
ФИО, GitHub и приватные данные в события не включаются. Перечитывание YAML,
смена недели и фоновое архивирование не отправляют событий — их изменения
страница увидит при запасном HTTP-опросе.

Frontend обновляет текущую очередь через существующий HTTP API. После удаления
старый снимок убирается. При уходе со страницы выполняется отписка и закрывается
соединение. При обрыве соединение восстанавливается через 2 секунды, затем
повторяются подписка и чтение данных. Раз в минуту остаётся запасной HTTP-опрос.
Список очередей преподавателя продолжает обновляться раз в 10 секунд — подписки
на курс не добавлены.

Ручки изменения очередей объявлены как `async def` и непосредственно вызывают
`await websocketService.send_event(queue_id, data)` после успешного изменения.
Блокирующие операции файлового хранилища и Google выполняются через
`asyncio.to_thread`, а сокеты используются только в основном asyncio loop.
У QueueService нет WebSocket-зависимости. `publish`, `bind`, `_loop`, `_tasks`
удалены; фоновые задачи не обращаются к транспорту.
Рассылка не держит блокировки состояния очередей и не отменяет успешные команды
при ошибке доставки. Отправки одному клиенту сериализуются; таймаут — 5 секунд.

nginx проксирует `/ws` с Upgrade, Vite имеет аналогичный WebSocket-прокси.
Хук `useQueueEvents` использует хост `VITE_API_BASE_URL` и путь `/ws`, выбирает
`ws`/`wss` по протоколу API. Для применения nginx и frontend пересоберите образы:

```bash
docker compose up -d --build
```
