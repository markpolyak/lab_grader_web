## Обновить GIF из MP4

Команда из корня репозитория; нужен FFmpeg. Она пересоздаёт только GIF, MP4 остаётся без изменений.

```bash
ffmpeg -y -i docs/assets/demo/presentation.mp4 \
  -filter_complex '[0:v]fps=12,scale=960:-1:flags=lanczos,split[a][b];[a]palettegen=max_colors=128:stats_mode=diff[p];[b][p]paletteuse=dither=bayer:bayer_scale=4:diff_mode=rectangle' \
  -loop 0 docs/assets/demo/presentation.gif
```

Ограниченная палитра и частота кадров уменьшают размер GIF. Для чтения мелких деталей и прослушивания звуков открыть MP4 либо скриншоты в исходном разрешении.
