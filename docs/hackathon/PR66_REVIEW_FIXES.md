## Что исправлено

| Пункт | Причина | Изменение |

| [1](https://github.com/markpolyak/lab_grader_web/pull/66#discussion_r4539746491) | Публичный эндпоинт принимал чужие `github` и `entry_id` без подтверждения личности и позволял выписывать стоящих впереди | В `main.py` удалён публичный эндпоинт `POST /courses/{course_id}/queue/leave`. Было решено не добавлять вход студентов, поскольку это существенно усложнило бы проект, и отказаться от самостоятельного выхода из очереди и уступки места. Преподаватель по-прежнему может снимать ожидающих и вызванных студентов через защищённый административный API с сохранением истории. |
| [3](https://github.com/markpolyak/lab_grader_web/pull/66#discussion_r4539746534) | `google: null` или строка вызывали ошибку при сборке настроек истории и останавливали backend | В `main.py` проверяется тип секции `google`. Некорректная секция пропускается для истории с предупреждением и ID курса. Настройки остальных курсов и глобальная настройка истории сохраняют действие. |
| [4](https://github.com/markpolyak/lab_grader_web/pull/66#discussion_r4539746554) | Студент видит неверное место в очереди: в нём учтены уже защитившиеся | Указанная проблема по факту не является актуальной. Благодаря использованию WebSocket таблица обновляется в момент изменения статуса защиты преподавателем. Все студенты сразу же могут видеть какой студент завершил защиту и кто должен идти сдавать следующим. В UI строки таблицы с уже завершенной сдачей даже отображаются серым цветом. Перенумерация после каждой защиты только запутает студентов и лишит их возможности видеть, кто на каком месте стоял изначально. Мы не считаем эту проблему обоснованной, поэтому изменений для ее исправления не совершали. |
| [6](https://github.com/markpolyak/lab_grader_web/pull/66#discussion_r4539746625) | Вызов `.strip()` у пустого `university` срывал генерацию расписаний всех курсов | В `queues/usecase/queue_service.py` сначала проверяется статус курса, затем наличие и тип университета. Неподдерживаемые курсы пропускаются, неверный тип активного курса логируется. Распознавание ГУАП/SUAI с пробелами и разным регистром сохранено. |
| [9](https://github.com/markpolyak/lab_grader_web/pull/66#discussion_r4539746715) | Три теста зависели от реальной даты | В тесте семестра напрямую подменены часы парсера; в двух тестах восстановления очереди `_now` зафиксирован внутри занятия и действует также после рестарта. |
| [10](https://github.com/markpolyak/lab_grader_web/pull/66#discussion_r4539746735) | Таблица не выводила уже доступное в API поле `joined_at` | Добавлена колонка времени записи по Москве с заголовками ru/en/zh. Исправлены `colSpan` пустой таблицы и ширина колонки действий. Отсутствующее или некорректное время показывается как `—`. |

В пункте 9 прежний `freeze_time` не подменял часы парсера: стандартный список
исключений freezegun содержит префикс `queue`, совпадающий с пакетом `queues`.
Поэтому в `tests/test_schedule_parser.py` используется локальная подмена
`queues.parser.parser.datetime`: 07.11.2026 12:00 UTC с преобразованием в
запрошенный часовой пояс. В `queues/tests/test_lesson_changes.py` время равно
`lesson.starts_at + timedelta(minutes=5)`. Подмены отменяются после каждого теста.
Рабочие правила закрытия очередей и код парсера для пункта 9 не менялись.

Для пункта 10 изменены `frontend/courses-front/src/components/queue-table/`
и `frontend/courses-front/src/locales/{ru,en,zh}/translation.json`.
Время отображается в 24-часовом формате `HH:mm`, часовой пояс указан в заголовке.
Общий компонент проверен в административном и студенческом представлениях.

Backend проверен локально на Python 3.14. Проверка CI на Python 3.11 отдельно
не выполнялась. Остались предупреждения зависимостей о deprecated API
и предупреждение Vite о размере bundle. Проверки UI выполнены рендером
настоящего React-компонента; отдельная визуальная проверка браузером не проводилась.

Регрессии добавлены в:

- `tests/review_repro/test_startup_broken_course.py`: некорректный `google`,
  скрытый курс, загрузка через администратора и рестарт.
- `tests/review_repro/test_foreign_course_breaks_queue.py`: доступность занятий
  рабочего курса рядом с черновиком через студенческий и административный API.
- `tests/review_repro/test_course_queue_config.py`: варианты типа и значения
  университета, статусы курсов, настройки истории и предупреждения.
- `frontend/courses-front/src/review_repro/queue_signup_time.test.js`: время
  ожидающих, UTC → Москва, переводы, заглушки и пустые таблицы.
