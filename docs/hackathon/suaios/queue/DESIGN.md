# Интерфейс очереди

Рабочий инструмент преподавателя и студента: светлый фон, нейтральные элементы управления, жёлтый для вызванного студента, зелёный для успешной защиты и красный для неудачной. Семейство Source Code Pro сохранено из основной темы сервиса. Цвет сопровождается текстовым статусом.

## Основа

`tokens.css` содержит три слоя: исходные цвета, размеры и интервалы → смысловые переменные → параметры компонентов. `appearance.js` связывает очередь с существующей темой. Шаг отступов — 4 px, поля и кнопки — не ниже 44 px, обычный текст — 14 px, подписи — 12 px. Заголовок страницы — 26 px; на узком экране — 22 px.

## Поведение

| Элемент | Правило |
|---|---|
| Подсказка | Наведение на пунктирную подпись или элемент; также фокус с клавиатуры. Escape закрывает. На сенсорном экране — удержание. Отдельных значков вопроса нет. |
| Вкладки | Подчёркивание активного раздела без изменения высоты панели. |
| Очередь | Два списка, три колонки; постоянные действия по состоянию строки. Вызванный жёлтый, успех зелёный, неудача красная. Повторы за пунктиром; места действий зарезервированы. |
| Статистика | Счётчики выбранного занятия; до начала неактивное оформление. |
| Ответ студента | Расположен перед списком, ответ сохраняет прежнюю серверную логику. |
| Форма | Постоянные подписи полей; две колонки на широком экране, одна на телефоне. |
| Малый экран | Таблица очереди переходит в последовательные карточки. Прокрутка расписания ограничена собственной таблицей. |
| Движение | Короткие переходы состояний; без декоративной анимации входа. При reduced-motion отключены. |

Изменение темы не меняет допуск, дедлайны, порядок очереди, фиксацию состава или результаты защиты. Проверки взаимодействий выполняются на искусственных данных; просмотр настоящего браузерного рендера в ограниченной среде недоступен.
