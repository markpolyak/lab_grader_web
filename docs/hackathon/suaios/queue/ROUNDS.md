# Очередь по кругам

## Списки и управление

Панель преподавателя содержит два списка: пришедшие/подтвердившие участие и отсутствующие/не подтвердившие. В каждом три столбца: номер, ФИО с GitHub, действия. Номер лабораторной в строках не показывается. Последний столбец самый широкий. Нумерация двух списков независима; в первом продолжается через пунктирную границу «Новый круг».

Кнопки каждой строки отображаются постоянно, независимо от её выбора. Их набор зависит от состояния:

- ожидает: «Вызвать» и удалённая вправо «Не пришёл»;
- вызван, жёлтый фон: «Сдал», «Не сдал», «Отменить вызов»;
- сдал: зелёная строка остаётся;
- не сдал: красная строка остаётся; при включённом автоповторе в конце появляется новая запись;
- не пришёл: активная строка уходит во второй список;
- отсутствует: «Пришёл» возвращает в конец нового круга независимо от прежнего подтверждения студента.

«Отменить вызов» возвращает ту же попытку на прежнее место. «Добавить студента» находится внизу первого списка и показывает список студентов курса/группы, известных по допускам и защитам. Уже ожидающего или вызванного добавить нельзя. При наличии следующей допущенной работы используется она; завершённую защиту текущего занятия преподаватель может вручную повторить, если следующей допущенной работы нет. Новый интерфейс не добавляет следующую лабораторную автоматически после «Сдал».

Несколько строк одного студента теперь обозначают разные попытки. Единственность активной попытки по предмету по-прежнему обеспечивается SQLite. Приоритет от −1 определяет первоначальную очередь; новый круг добавляется в хвост.

## Настройки и отмена

Отдельная вкладка «Настройки»: автоповтор неудачной защиты и время отмены 1–10 секунд. Ползунок и числовое поле синхронизированы. Параметры применяются после «Сохранить настройки»; строка «Настройки сохранены» показывается после успешного ответа.

После «Сдал», «Не сдал», «Не пришёл», «Пришёл» и ручного добавления показывается временное уведомление с «Отменить» и крестиком. Крестик только закрывает уведомление. Отмена восстанавливает исходную попытку и убирает созданное продолжение; журнал действий сохраняется. Срок отсчитывается после обработки команды и обновления данных. Сервер отклоняет просроченную отмену, отмену чужого действия и откат поверх последующих изменений или подтверждения защиты таблицей.

Новые попытки добавляются только до окончания пары. Ожидающих можно принимать до конца местного дня. Для проверки без реальных сервисов доступна [песочница](SANDBOX.md).


Студент во время занятия и десять минут после видит это же представление без кнопок. Затем отображается следующее доступное занятие и открывается изменение посещения. Запрос на запись в следующую пару до этой границы сервер отклоняет. Ошибки действий показываются фиксированным всплывающим уведомлением с возможностью закрыть его.


## Формирование следующего списка

В режиме «Случайная» место заранее получает каждый студент группы, даже без готовой работы. Случайный ключ сохраняется в SQLite для конкретного занятия: обновление страницы или регистрация лабораторной порядок не меняют. На другое занятие создаются новые ключи. Все по умолчанию в списке «Не придут».

В режиме «−1» выбирается первая готовая работа после последней защищённой. Пустые ячейки пропускаются, старые незакрытые работы перед последней защищённой игнорируются. Если следующая работа ещё не готова, предварительный приоритет рассчитывается по её дедлайну. Завершившие все работы в новый список не включаются. Предварительное место не позволяет подтвердить приход без допуска.

Если таблица во время занятия подтвердила более позднюю защиту, устаревшая ожидающая попытка закрывается. Новая готовая работа получает место в конце повторного круга, а не приоритет старой работы. Уже вызванная попытка остаётся у преподавателя для завершения; автоматический повтор устаревшей работы не создаётся.
