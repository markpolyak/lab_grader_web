# D1: дневная очередь без расписания

При включённой очереди без расписания автоматически создаётся дневная сессия группы в часовом поясе курса. Она сохраняется после перезапуска, доступна до следующей местной полуночи; новый день получает отдельное участие. Явная отмена назначенной пары не заменяется дневной очередью до окончания её интервала.

Регрессионные тесты: `tests/test_queue_review_daily.py`. Обычные сессии сохраняют прежнюю фиксацию состава. Миграция 009 вводит режим посещения, позволяющий дневной очереди работать после начала суток.
