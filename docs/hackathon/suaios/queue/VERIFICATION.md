## Воспроизведение

Из корня репозитория после установки зависимостей:

```bash
ADMIN_LOGIN=test ADMIN_PASSWORD=test SECRET_KEY=test GITHUB_TOKEN=dummy QUEUE_WORKER_ENABLED=0 .venv/bin/python -m pytest tests/ -q
npm test --prefix frontend/courses-front
npm run build --prefix frontend/courses-front
./start-sandbox --check
.venv/bin/python scripts/check_docs.py
```

Внешние Google/GitHub в сценариях песочницы симулируются. Проверка публичных источников требует сети: `./start-main --check`. Полный цикл на собственной таблице и репозиториях требует собственных ключей из [RUNBOOK](RUNBOOK.md).

## Командные решения и требования задания

Команда сохраняет утверждённые правила. Техническая готовность этих сценариев не означает согласование отличий с организатором.

| Пункт | Как реализовано |
|---|---|
| Основной порядок | Приоритет с границей −1, при недоступных сроках — случайный режим; преподаватель может включить случайный вручную |
| Начало записи | Список виден заранее; посещение меняется до начала пары, а не только в окне за несколько минут |
| Следующее занятие | Открывается после окончания текущего + 10 минут; до этого студент смотрит текущую очередь |
| Выбор работы | Первая доступная после последней защищённой, с пропуском пустых ячеек |
| Результаты защиты | Сохраняются в истории очереди; существующие оценки Google Sheets модуль не изменяет |
| Неявка | Преподаватель отмечает отдельно; отсутствие подтверждения «Приду» не является неявкой |
| Идентификация студента | Существующая форма ФИО/GitHub; новый OAuth-вход не вводился |
| Хранение | SQLite, постоянный каталог, миграции и история |

[Исторический аудит 07.11](AUDIT-2026-11-07.md) сохраняет промежуточные выводы. Для текущего интерфейса и правил используются [ROUNDS](ROUNDS.md), [ADR-0001](../../../adr/0001-priority-policy.md) и этот протокол.

## Переносимость CI
